# gempabumi
Aplikasi web berbasis Python dan Streamlit untuk menampilkan, menganalisis, dan memvisualisasikan data gempa bumi dunia berdasarkan kekuatan magnitudo, lokasi, dan periode waktu. Aplikasi ini membantu pengguna memahami persebaran aktivitas gempa bumi melalui visualisasi data yang interaktif dan informatif.
